# xauusd-signal-lab

XAUUSD（ゴールド）専用のトレードシグナル検証リポジトリです。

このリポジトリの目的は、MT4から取得したXAUUSDの価格データを使い、Pythonでバックテスト・シグナル判定・機械学習フィルター・Discord通知まで拡張できる土台を作ることです。

最初の目的は自動売買ではありません。
裁量判断を補助するための高精度シグナル通知ツールを作ることを目的とします。

## 最終的に目指す流れ

```text
MT4からXAUUSDデータ取得
↓
Pythonでインジケーター・特徴量計算
↓
ルールベースでシグナル候補を生成
↓
バックテストで成績検証
↓
機械学習でシグナルをフィルター
↓
Discordに通知
↓
必要に応じてAIで状況評価
↓
最終判断は人間が行う
```

## 初期方針

```text
対象銘柄：XAUUSD
メイン足：M15
上位足：H1
売買方針：H1方向への順張り
初期RR：1:1.5以上
MACD：TradingView / Pine Script と同じ設定値をPython側で再計算
ダイバージェンス：主にヒドゥンダイバージェンスを順張り条件として扱う
通常ダイバージェンス：初期段階では見送り要素として扱う
```

## 現時点の最初のゴール

```text
XAUUSDのM15/H1 CSVを読み込み、
Pine互換MACDと確定スイングを使って、
ヒドゥンダイバージェンス順張りシグナルを作り、
RR1.5固定でバックテスト結果を出す。
```

## 注意

このリポジトリでは、最初から自動売買EAを作らない。
まずはバックテストで検証できる土台を作り、成績と問題点を確認してからリアルタイム通知・機械学習・AI評価へ進む。
