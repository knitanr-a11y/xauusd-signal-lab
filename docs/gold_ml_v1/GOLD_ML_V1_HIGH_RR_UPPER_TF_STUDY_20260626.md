## 結論

高RR LONGの勝率を小利確で作るのではなく、上位足構造で初期SLを減らした。

追加gate:

- H4 `(20本最高値 - 終値) / ATR14 <= 3.7864707809`
- H1 `(終値 - 6本前終値) / ATR14 <= -0.8532783779`

- entry時点で完全に確定済みのH4・H1のみ使用
