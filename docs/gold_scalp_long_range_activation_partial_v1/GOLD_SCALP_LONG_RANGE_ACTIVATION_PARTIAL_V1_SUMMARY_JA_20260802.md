# GOLDスキャルピング LONG／レンジ activation研究 結果

## 結論

- レンジ反発追随：不採用
- レンジ反発失敗の逆方向継続：不採用
- トレンドLONG：2つの観察候補を追加
- 正式ポートフォリオ：なし

## 残したトレンドLONG候補

### EFFORT_RESULT_CONT LONG

- 上位足方向と一致
- 15分以内に+3ドル、先に-1ドルへ行かない
- 1ドル押し戻し後、activation水準を再回復
- 次のM1始値でLONG
- 50%を+5ドル、残りを建値へ移し+10ドル、SL5ドル

記述的全履歴：53件、勝率60.38%、PF1.70、+68.42ドル、DD20.23ドル。

### HTF_PULLBACK_RESUME LONG

同じactivation／出口契約。

記述的全履歴：47件、勝率65.96%、PF2.08、+86.56ドル、DD15ドル。

どちらも結果確認後に抽出したため、正式候補ではなく観察候補です。
