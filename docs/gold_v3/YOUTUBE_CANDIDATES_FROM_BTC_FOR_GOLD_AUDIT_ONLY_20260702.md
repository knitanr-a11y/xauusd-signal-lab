# YouTube候補1

## `BTC4_RISK_CAP_400`

### 基本構造

- H4 EMA20・EMA200、適用価格Close。
- 明瞭なEMAクロス後にEMA20への押し戻りを待つ。
- EMA20タッチ足のヒゲがEMA200を越える場合、その足だけを基準足から外し、次の有効タッチを待つ。
- エントリー前に終値でEMA200を否定、またはEMA20が逆クロスした場合は見送り。
- 有効基準足の高値・安値をH4終値で抜けた後、次のM5始値で入る。
- エントリー後はEMA200を決済条件にしない。
- 構造SL、TP1半利、残り建値、TP2の契約。
- BTCでは予定構造リスク400pips以下だけを採用。

### BTC結果

- 勝率77.78%
- PF 2.913
- 合計 +1,016.44pips
- 最大DD 289.13pips
- BTC固定ロット 0.02

### GOLDで再探索する項目

- GOLDのEMA20/200で同じ基準足契約が成立するか。
- GOLD用の構造SL上限。BTCの400pipsを流用しない。
- GOLDのスプレッドを含めたEntry・SL・TP計算。
- GOLD用ロット。
- GOLD用最低利益幅。

# YouTube候補2

## `BTC5_TWO_PIVOT_P2_CLEAN_N_382_786`

### 基本構造

- M5 EMA20・EMA200、適用価格Close。
- EMA20がEMA200の上ならLONG、下ならSHORT。
- EMA20が逆クロスするまで、2回目以降を含む各EMA200タッチを有効とする。
- ヒゲだけのEMA200タッチも有効。
- 連続してEMA200へ触れている足は1接触群。一度離れた後の再接触は別候補。
- タッチ前24時間以内の直近確定波をA-Bとする。
- タッチ後最初の確定押し安値・戻り高値をCとする。
- BC/AB戻し率は0.382～0.786。
- ピボット幅2の2点斜めラインを使用。
- M5終値でラインを抜け、次のM5始値で入る。
- TPはAB=CD。
- BTCではC点の外側30pips。BTC契約では価格差300ドル。
- BTCでは純利益50pips以上、`1 < RR < 3`。

# GOLD探索時の絶対契約

## データと時間

- CSV `time` は足の始値として扱う。
- 終値確定を使う条件は、必ず足の終了後に判定する。
- エントリー価格には、判定足の次に実際に約定可能な始値を使用する。
- open中の足、未来のTP・SL・exit、未確定ピボットを候補選択に使わない。

## 資産固有値

GOLDへ流用してはいけないもの:

- BTCのpip定義 `$10値動き=1pip`
- BTCのスプレッド20～30ドル
- BTCのC点外側30pips＝価格差300ドル
- BTCの最低利益50pips
- BTC4の400pips上限
- BTCの固定0.02ロット

GOLDでは以下を先に固定してから結果を計算する:

1. GOLDのpip・point契約
2. 想定スプレッド
3. SLバッファ候補
4. 最低利益幅
5. RR範囲
6. ロット
7. 探索期間・確認期間・未評価フォワード期間

## 条件選択

- 候補・ゲート・ライン・ピボットはエントリー時点で分かる情報だけで決定する。
- 成績が良い設定を後から採用しない。
- 複数定義は探索期間と確認期間を分離して比較する。
- 未来損益を使って条件を決めない。
- 同じYouTube構造でも、BTCとGOLDは別候補として独立評価する。

## GOLD V3境界

GOLDでの検証はaudit-onlyで行う。

以下は読まない・使わない・参照しない・fallbackにしない:

- GOLD V2
- 旧GOLD
- DISC8
- Stage41 feature-only snapshot

新しいYouTube候補は、既存候補を置き換えず、独立したcandidate familyとして追加する。
