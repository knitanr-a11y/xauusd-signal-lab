# GOLD V3 Stage260 E4 定義固定
## 長時間圧縮後の初回拡大

作成日: 2026-06-20
状態: `GOLD_V3_260_E4_DEFINITION_LOCKED_AUDIT_ONLY`

## 目的

弱いセットアップへ条件を追加するのではなく、長時間圧縮後の初回拡大という母集団自体が、同条件の非イベント時点より将来値幅分布を改善するか確認する。

E4は二段階に分ける。

- E4A: 圧縮後の初回拡大イベントの母集団監査
- E4B: E4A合格時だけ、初回リテスト後の価格受容を入口として監査

E4Aが不合格ならE4Bへ進まない。

## 絶対契約

- audit-only
- CSV最新行はclosed
- CSV `time`は足のOPEN時刻
- M1はOPEN+1分、M5は+5分、M15は+15分、H1は+1時間、H4は+4時間後から利用可能
- すべてのHTFは`source_close_time <= decision_time`
- 圧縮箱は拡大M5が始まる前に確定済みでなければならない
- 同一M1でTP/SLへ触れた場合はSL優先
- MFE/MAEはSL先着後も固定ホライズン終端まで計算
- 別CSVは時刻結合のみ
- 1 setup 1 trade
- 2025H1で発見、2025H2で選定、2026は無変更固定
- 2026を見て2025条件を変更しない
- 実運用、注文、通知、live hook、order payloadを作らない

## E4A 圧縮定義

圧縮判定足は確定済みM15。

1. 直近12本の完了M15、すなわち3時間を圧縮窓とする。
2. 圧縮箱上限は12本の最高値、下限は12本の最安値。
3. 箱幅を、当該時点より前の960個の同じ12本箱幅と比較する。最低480履歴を必要とする。
4. 12本のM15 true range中央値も、当該時点より前の960履歴と比較する。
5. 次の両方を満たす場合だけ圧縮とする。
   - 箱幅の因果過去分位 `<= 20%`
   - M15 true range中央値の因果過去分位 `<= 25%`
6. 分位計算へ将来値を入れず、比較履歴から現在値も除外する。

## E4A 初回拡大定義

判定足は確定済みM5。

1. 拡大M5のOPEN時刻以前に利用可能だった、最新の圧縮M15箱を使用する。
2. LONGはM5確定終値が箱上限を因果H1 ATR14の0.08倍以上上抜く。
3. SHORTはM5確定終値が箱下限を因果H1 ATR14の0.08倍以上下抜く。
4. 拡大M5のtrue rangeは、直前576本の完了M5 true rangeの因果過去分位で80%以上。最低288履歴を必要とする。
5. 現在の固定箱に対し、直前6本のM5終値が同方向へ箱外確定していないことを必須とする。
6. decision_timeは拡大M5の確定時刻。
7. 評価entryはdecision_timeと同時刻に始まる次のM1始値。
8. 120分のactive期間中は新しいE4 setupを作らない。方向反転も別setupにしない。

## E4A 評価

- horizon: 60 / 120 / 180 / 240分
- TP: 5 / 10 / 15 / 20 / 25ドル
- SL: 5 / 10 / 15ドル
- cost: 0 / 1 / 2 / 3 / 5ドル
- full-horizon MFE / MAE
- 5 / 10 / 15 / 20 / 25ドル到達率と到達時間
- 2.5 / 5ドル逆行後の回復
- PF、期待値、PnL、最大DD、最大連敗
- 月、四半期、半期、方向、MT5時間、H1/H4 ATR帯

## matched control

イベント1件につき非復元で1件を対応させる。

一致条件:

- 同じ曜日
- 同じMT5サーバー時間
- 同じ方向
- 同じH1 ATR過去分位帯
- 同じH4 ATR過去分位帯
- 同じ圧縮箱幅分位帯
- 同月、なければ同四半期、さらに不足時だけ90日以内
- entry前後30分にE4イベントがない

正確なStage258レジーム時系列が得られた場合は同レジームを追加する。得られない場合、proxyレジームは作らず、その制約を明記する。

## プラセボ

- event time ±5 / ±10 / ±15分
- direction reversal
- 箱境界 ±0.25 H1 ATR
- 圧縮条件を外したexpansion-only
- 初回条件を外し、直前に同方向箱外終値があるnot-first expansion
- 同月内で圧縮flagをランダム置換
- 同件数random event flag
- 曜日入れ替え

## 事前採否基準

E4Aを次へ進めるには最低限すべて必要。

1. 120分MFE平均がmatched controlより2.0ドル以上大きい。
2. 120分MAE平均がmatched controlより1.0ドル超悪化しない。
3. 固定グリッド全体の最大cost0期待値が3.0ドル以上。これは上限診断であり選定値にはしない。
4. 2025H1だけで選んだcost2最良セルが期待値プラスかつPF 1.10以上。
5. その固定セルが2025H2でも期待値プラスかつPF 1.10以上。
6. 真のE4が主要な時刻・境界・random・expansion-onlyプラセボより良い。
7. 月または単一方向だけで全利益を説明できない。

1〜3の母集団早期条件を満たさなければ、特徴量追加やE4Bへ進まない。

## E4B 初回リテスト受容

E4A合格時だけ実行する。

1. E4A decision_timeから30分以内。
2. 突破境界へ0.05 H1 ATR以内まで初回接近。
3. その後の確定M5が、境界から突破方向へ0.03 H1 ATR以上戻って確定。
4. entryは受容M5確定時刻に始まる次のM1始値。
5. リテスト前の結果や将来の最良入口は使用しない。
