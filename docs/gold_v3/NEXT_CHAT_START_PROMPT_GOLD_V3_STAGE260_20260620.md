最初に行うこと:

1. 引き継ぎファイルを最後まで読む
2. 必要なGOLD V3ファイルとCSVの存在を確認する
3. 禁止ソースを開かない
4. source parityを確認する
5. MT5セッションカレンダーを再構築または検証する
6. E2イベント定義をコード実装前に文書化する
7. イベント群と非イベント対照群を先に比較する
8. 母集団自体に差がある場合だけ追加特徴量を検討する

必須のmatched control条件:

- 同じ曜日
- 同じMT5時間帯
- 同じATR帯
- 同じHIGH／NORMAL／TRANSITIONレジーム
- 同じ方向条件
- 近い月または四半期
- ただし対象イベントは発生していない

必須評価:

- MFE
- MAE
- MFE/MAE比
- TP/SL先着
- 5／10／15／20／25ドル到達
- 到達時間
- 逆行後回復率
- cost0／cost1／cost2／cost3
- PF
- 損益
- 期待値
- 最大DD
- 最大連敗
- 月別
- 四半期別
- LONG／SHORT別
- 2025年前半
- 2025年後半
- 2026年固定検証
- レジーム別
- セッション別

必須プラセボ試験:

- イベント時刻を±5／±10／±15分シフト
- 水平価格を±0.5／±1.0ATRシフト
- LONG／SHORT反転
- 日付ランダム化
- 曜日入れ替え
- レジーム逆割当
- event flagを同件数のランダム時点へ置換
- 確認条件を外した母集団との比較

イベント母集団自体に明確な差がない場合は、条件や特徴量を追加して見栄えを良くせず、そのイベントを早期不採用にしてください。
