# GOLD V3 Stage280 上位足伸長・下位足分解監査（2026-06-22）

正式状態: `GOLD_V3_280_HTF_EXPANSION_PRECURSOR_FOUND_SHADOW_ONLY_NO_ACTIVE_PROMOTION_AUDIT_ONLY`

## 結論

H1で大きく伸びた局面を先にラベル化し、直前のM1・M5・M15と確定済みH1・H4・D1へ分解した。単純に全M5足から利益を直接当てるStage279とは異なり、今回は次の二段階である。

1. H4方向へ戻る `CONT`（順張り再開）と、H4方向へ逆らう `REV`（上位足反転）を分離する。
2. 上位足伸長の予兆をMLで検出した後、M5で実際の切り返しを確認してから入る。

**上位足反転（REV）の予兆は未見年でも安定して検出できた。** 一方、順張り再開（CONT）は2026年に崩れた。

売買候補では `REV_LONG_Q95_BRK6_E175` が2024・2025・2026の全てで候補単体プラスだった。ただし件数は12・17・11件と少なく、利益集中が大きく、459件版へ統合した2026年最大DDが52.48から76.20へ増えた。そのためACTIVE追加は行わず、研究SHADOW候補としてのみ保存する。

## 1. 上位足伸長ラベル

H1開始時点の価格から今後4時間をM1で判定し、次を満たす方向を「H1伸長」とした。

- 最大順行: 2.0 ATR以上
- 4時間後の残存: 0.75 ATR以上
- 最大逆行: 1.25 ATR以下
- 最大順行 / 最大逆行: 1.5以上
- 同方向の連続ラベルは、直前3時間に同方向ラベルがあれば除外して開始点だけ残す

| 分類 | 件数 | 定義 |
|---|---:|---|
| CONT | 513 | 伸長方向が直前に確定したH4トレンドと同方向 |
| REV | 540 | 伸長方向が直前に確定したH4トレンドと反対方向 |
| NEUTRAL | 508 | H4方向が中立、または上記以外 |
| 合計 | 1561 | LONG・SHORT両方 |

### H1始値で即エントリーできない理由

最後の5～15分は、年をまたいで一貫した同方向反転にはなっていなかった。つまりH1開始時点は「逆行の終了候補」ではあるが、まだ底・天井の確定前である。このためH1始値で入る候補は損失集中とDD悪化が大きかった。

そこで、ML予兆の後にM5の切り返しを待つ二段階構造へ変更した。

## 4. 下位足Trigger

REV予兆後60分以内に、次のM5切り返しを固定比較した。

- 過去3本高安ブレイク
- 過去6本高安ブレイク
- EMA8回復
- EMA20回復

Trigger barの確定後、次のM5始値でentryする。基準459件が保有中なら入らず、候補保有中に基準シグナルが出れば基準entry時刻のM1始値で候補を終了する。
