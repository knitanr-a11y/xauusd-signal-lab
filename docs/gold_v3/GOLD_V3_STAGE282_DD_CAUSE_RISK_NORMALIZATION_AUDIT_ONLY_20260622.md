# GOLD V3 Stage282 DD原因・ドルリスク正規化監査（2026-06-22）

正式状態:
`GOLD_V3_282_DD_CAUSE_CONFIRMED_RISK_NORMALIZATION_SHADOW_ONLY_AUDIT_ONLY`

## 結論

Stage281の2026年DD58.87ドルは大きい。
ただし、原因は「2026年に極端な長期連敗が起きた」ことではない。

2026年の候補単体最大DDは、2026-03-11の2回の連続フルSL、
-30.92ドル、-27.95ドルでほぼ形成された。

Stage281はSLを1.25×確定H1 ATRとしている一方、
成績表は固定1oz相当のドル損益で集計している。
H1 ATRの絶対ドル幅が上昇したため、同じ1Rの損失でもドル損失が大きくなった。

## 年別の1回あたりドルリスク

| 年 | H1 ATR中央値 | フルSL損失中央値 | 最大フルSL損失 | ドルDD | R換算DD |
|---|---:|---:|---:|---:|---:|
| 2024 | 5.51 | 7.49 | 13.87 | 26.99 | 5.63R |
| 2025 | 7.66 | 10.17 | 18.81 | 33.54 | 5.79R |
| 2026途中 | 18.62 | 23.88 | 30.92 | 58.87 | 2.04R |

2026年はドルDDが最大だが、R換算では3年間で最小だった。
したがって、2026年DDの第一原因は予測精度の崩壊よりも、
固定数量のままATR連動ストップを使ったことによるドルリスク拡大である。

Stage281レポートのLOW/MID/HIGHはATR14/ATR50の相対比であり、
LOWは「ドル幅が小さい」という意味ではない。
2026年3月の損失局面は相対ATR比0.79～0.85でLOW側だったが、
H1 ATRの絶対値は20.58～24.26ドルだった。

459件版との統合DD90.10ドルは次の流れで発生した。

4. Stage281: +1.46

Stage281の5件は、すべて2026-03-10 20:17に決着した同じ基準損失を起点とし、
約41.5時間以内に集中していた。

Stage280も加えたDD131.16ドルは、
その後2026-03-18にStage280が-17.11、-23.95と続いたためである。
候補同士が同時エントリーしたのではなく、同じ不安定期間に連続してリスクを追加した。

## 主因ではなかったもの

2026年3月のStage281取引を確認した。

- H4 trend: 全件LONG方向
- D1 trend: 全件LONG方向
- entry付近spread: おおむね0.24～0.29ドル
- 保有中最大spread: 0.28～0.32ドル
- 最大M1 gap: 0.131 ATR以下
- 最大M1 range: 0.552 ATR以下

以前のsevere microstructure proxyである
spread 0.50ドル、gap 0.50ATR、range 3ATRには該当しない。

したがって主因は、
- 上位足方向不一致
- rollover
- 異常spread
- ニュース級M1 shock
ではなかった。

## 候補集中ガード

次を小さな固定gridで確認した。

- 同じ基準損失につき最大1～3回
- 候補損失後12～72時間停止
- 同じ基準損失で1回負けたら停止
- 1日最大1～2回

これらは2026年DDを減らしたが、2025年の統合DD58.46を一貫して解消しなかった。
また1日1回などの暦日境界は構造的根拠が弱いため、正式gateには採用しない。

## ドルリスク上限の診断

2024年のフルSL損失中央値7.4867ドルを丸め、
候補の1回あたりフルSL損失を最大7.5ドル相当に抑える診断を行った。

式:
`size_multiplier = min(1, 7.5 / (1.25*closed_H1_ATR14 + 0.60))`

この値はentry時点で確定済みH1 ATRから計算できる。
シグナル、候補件数、TP/SL比率は変えず、候補の数量だけを縮小する。
