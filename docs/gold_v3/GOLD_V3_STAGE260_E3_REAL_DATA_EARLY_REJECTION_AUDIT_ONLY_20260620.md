## 1. 結論

E3は、単純なbreakout-onlyまたはretest-onlyより粗成績を改善した。しかし、事前固定した最低基準へ届かず、2025年前半のcost2候補も全固定セルで赤字だったため不採用とする。

主な理由:

- 全固定グリッド最大cost0期待値は`+1.81 USD`で、事前基準`+3 USD`未満。
- 2025年前半のcost2最良セルは期待値`-1.69 USD`、PF`0.52`。
- 同セルは2025年後半`-2.89 USD / PF 0.32`、2026年前半部分`-4.69 USD / PF 0.20`。
- 固定セルのcost2月別は、プラス1か月、マイナス15か月。
- random flagの粗上限`+2.76 USD`が真のE3`+1.81 USD`を上回った。
- matched controlは厳密一致で8組しかなく、差の95%区間はゼロを含んだため、対照群優位は確認不能。

EMA、出来高、時間帯、方向、レジーム等を追加して救済しない。
