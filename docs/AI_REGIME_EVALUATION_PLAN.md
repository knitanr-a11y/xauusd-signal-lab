# AI相場環境評価プラン

このドキュメントは、バックテストで悪かった期間を単純に削るのではなく、
その期間の相場状態を記録し、将来のリアルタイム通知時にAIへ読ませて評価材料にするための設計メモです。

## なぜ単純に削らないのか

特定の月や特定の負け方に合わせて条件を削ると、その期間には最適化できても、
他の期間で利益になっていたトレードまで消す可能性がある。

特に、現在の `xm_kiwami_gold_abc_v3` は長期でプラスが出ているため、
一部の弱い月だけを理由にA/B/C/C2の条件を大きく変えるのは危険。

## 基本方針

- ルール本体はまず壊さない。
- 悪かった期間を「負けパターン事例」として保存する。
- 勝っている期間・勝ちトレードも同じかそれ以上に保存する。
- AI評価は「負け回避」だけに偏らせない。
- 将来シグナルが出たとき、現在の相場が過去の勝ちパターンに近いかをまず確認する。
- そのうえで、過去の負けパターンにも似ていないかを警告材料として確認する。
- AIは最終判断をせず、裁量確認の注意点を出す。
- 最終判断は人間が行う。

## AI評価で避けたい偏り

負けた場面だけをAIへ読ませると、AIは「似ているリスク」を過大評価しやすくなる。
その結果、実際には期待値があるシグナルまで「注意」「見送り候補」に寄りすぎる可能性がある。

そのため、AI評価では以下の比率を基本にする。

```text
勝ちパターン: 60〜70%
負けパターン: 30〜40%
```

AIにやらせたいことは、単純な負け回避ではない。

```text
このシグナルは、過去の勝ちパターンにどれだけ近いか。
同時に、過去の負けパターンにも危険なほど似ていないか。
```

この2軸で評価する。

## AI評価の優先順位

AIには、以下の順番で評価させる。

### 1. 勝ちパターンとの一致度

まず、現在のシグナルが過去の勝ちトレードに似ているかを見る。

見る項目:

- モデル種別 A / B / C / C2
- BUY / SELL
- JST時間帯
- H1環境認識
- M15の形
- EMAの並び
- MACDの状態
- ATRとrisk/ATR
- ブレイク後の維持力
- 押し目・戻り目の自然さ

### 2. 負けパターンとの類似度

次に、過去の負けトレードに似ていないかを見る。

見る項目:

- 抜けた直後に押し戻されやすい形か
- 上位足と下位足の方向が噛み合っていないか
- ボラティリティが急拡大・急縮小していないか
- SLが近すぎるか
- 直近のローソク足に長いヒゲが多いか
- 連敗が発生しやすかった相場状態に似ているか

### 3. 総合判定

勝ちパターンにも負けパターンにも似る場合がある。
その場合は、AIに「どちらの根拠が強いか」を比較させる。

```text
勝ちパターン一致度: 高 / 中 / 低
負けパターン類似度: 高 / 中 / 低
総合判定: 通常 / 注意 / 強い注意 / 見送り候補
```

## 2025年3月の位置づけ

`xm_kiwami_gold_abc_v3` の2025年3月は、長期成績の中では弱い月だった。

概要:

```text
14回
5勝9敗
-1.5R
PF 0.833
DD 6.0R
```

モデル別:

```text
A: 4回 / 1勝3敗 / -1.5R
B: 2回 / 0勝2敗 / -2.0R
C: 8回 / 4勝4敗 / +2.0R
```

重要:

- 2025年3月は、Cだけが悪いわけではない。
- AとBがマイナスで、Cは月間ではプラス。
- 単純にCを削ると、後半で取り返した勝ちも消える可能性がある。
- そのため、2025年3月は「条件削除」よりも「AIに読ませる負け相場サンプル」として扱う。
- ただし、負けサンプルだけを強く読ませると見送り過多になるため、同時に勝ちサンプルも保存する。


## AIに読ませたい情報

将来シグナルが出たとき、AIには以下を渡す。

### 1. 現在のシグナル情報

- ブローカー
- 口座種別
- シンボル
- 時間足
- モデル種別 A / B / C / C2
- BUY / SELL
- シグナル時刻
- JST時刻
- エントリー候補価格
- SL
- TP
- リスクリワード
- risk / ATR
- ATR
- スプレッド

### 2. 上位足の状態

- H1方向
- H1 EMA20 / EMA50 / EMA200 の位置関係
- H1 EMA乖離
- H1の直近高値安値
- H1がトレンドかレンジか
- H1のボラティリティ拡大/縮小

### 3. M15の状態

- M15 EMA20 / EMA50 / EMA200 の位置関係
- MACDライン
- MACDシグナル
- MACDヒストグラム
- MACDヒストグラム加速/減速
- 直近スイング高値安値
- ブレイク直後か、押し戻されているか
- 直近数本のローソク足の実体/ヒゲ

### 4. 過去の勝ちパターン

例:

- トレンド方向とシグナル方向が一致
- H1の方向性が明確
- M15で押し目・戻り目が自然
- EMA20を維持しながら再加速
- MACDヒストグラムが素直に伸びる
- ブレイク後にすぐ押し戻されない
- risk/ATRが極端すぎない

### 5. 過去の似た負けパターン

例: 2025年3月の負け相場

- 月初〜中旬に負けが集中
- 上に抜けたように見えてC BUYが押し戻される
- A/Bも少数ながら損失
- BUY/SELLどちらか一方だけではなく、方向感が不安定
- 複数日でSLが続いた

## AIに聞くこと

リアルタイム通知時のAI評価では、以下を聞く。

```text
このシグナルは、過去の勝ちパターンに近いですか？
どの勝ちパターンに近いですか？
同時に、過去に負けが集中した2025年3月のような相場状態に似ていますか？
似ている場合、どの点が似ていますか？
違う場合、どの点が違いますか？
勝ちパターン一致度と負けパターン類似度のどちらが強いですか？
エントリーを見送るべき注意点はありますか？
SLが浅すぎる、または押し戻されやすい形になっていませんか？
上位足と下位足の方向が噛み合っていますか？
```

## AI出力の理想形

AIには、以下のような出力をさせる。

```text
判定: 通常 / 注意 / 強い注意 / 見送り候補

勝ちパターン一致度: 高 / 中 / 低
負けパターン類似度: 高 / 中 / 低

理由:
- H1は上向きで、M15もEMA20を維持しており、過去の勝ちC BUYに近い
- 一方で、直近足に上ヒゲがあり、ブレイク後の押し戻しリスクはある
- 2025年3月の負けパターンに一部似ているが、H1方向とMACD加速は今回の方が良い

確認ポイント:
- 次のM15足で高値を維持できるか
- EMA20上で終値を維持できるか
- 直近安値を割らないか
```

## やってはいけないこと

- AIに最終エントリー判断を丸投げしない。
- AIの評価だけで売買しない。
- 一つの悪い月だけを理由にルールを削りすぎない。
- 負けケースだけを読ませて、AIを見送り寄りにしすぎない。
- 成績が良い期間を無視して、悪い期間だけに最適化しない。
- バックテスト条件とリアルタイム評価条件を混同しない。

## 実装ステップ

### Phase 1: 勝ち相場・負け相場ケースの保存

- 2025年3月の負けトレードをCSVとして保存する。
- 勝ち月の代表トレードもCSVとして保存する。
- 月別要約をMarkdown化する。
- A/B/C/C2別、BUY/SELL別、時間帯別に特徴を残す。

### Phase 2: シグナルごとの説明データ作成

- シグナル発生時に、AIへ渡すJSONまたはMarkdownを作る。
- 価格、ATR、MACD、EMA、H1状態、直近ローソク足を含める。

### Phase 3: AI評価プロンプト作成

- 過去の勝ちケースと現在シグナルをまず比較させる。
- 次に、過去の負けケースとも比較させる。
- 出力は「通常 / 注意 / 強い注意 / 見送り候補」に統一する。

### Phase 4: Discord通知に追加

- Discord通知にAI評価を追記する。
- ただし、AI評価は補助情報として扱う。

## 現時点の結論

`xm_kiwami_gold_abc_v3` は長期で有望。

そのため、次の方針は以下。

```text
ルールをすぐ削るのではなく、勝ち相場と負け相場の両方をケース集として保存する。
将来シグナルが出たとき、現在相場が勝ちパターンに近いかをまず確認する。
そのうえで、負け相場にも似ていないかをAIで評価する。
```
