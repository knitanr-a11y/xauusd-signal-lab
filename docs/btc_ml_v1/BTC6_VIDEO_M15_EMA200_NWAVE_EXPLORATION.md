# BTC-6 M15 EMA200・N波動探索

## 目的

BTC5で機械化した動画手法をM15へそのまま展開し、別時間軸の候補として件数を積み増せるか確認した。

時間足だけをM15へ変更し、24時間・6時間などのルールは時間で同一になるよう換算した。

## 固定条件

- M15のEMA20・EMA200、適用価格Close。
- EMA20がEMA200の上ならLONG、下ならSHORT。
- 逆クロスまで2回目以降のEMA200タッチも有効。
- ヒゲだけの接触も有効。
- 連続接触足は1回のタッチ群。
- ラインをM15終値で抜け、次のM15始値で入る。
- A-B探索範囲は24時間＝96本。
- C点の外側30pips＝価格差300ドルをSL。
- TPはAB=CD。
- 純利益50pips以上。
- `1 < RR < 3`。
- 同一M15足でSLとTPが両方成立する場合はSL優先。

## 比較した方式

- 確定ピボット幅2・3・5。
- 2点ピボット斜めライン。
- 3点以上の回帰線。
- ダブルトップ／ダブルボトムのネックライン。
- BC/AB戻し率:
  - 0.236～0.886
  - 0.382～0.786
  - 0.500～0.886

## 全比較

- ダブルトップ／ボトムのピボット幅2は探索PF 1.734だったが、確認PF 0.365で崩れた。
- 回帰線は最大4件しかなく、判断不能。
- 2点ライン・ピボット幅2は探索PF 1.671、確認PF 1.324だが、標準N波動帯へ絞ると確認1件しか残らない。
- 2点ライン・ピボット幅3の広いN波動帯0.236～0.886は、探索8件・確認5件で両期間ともPF約1.6を維持した。
- ピボット幅5は探索期間が不安定。

## 暫定候補

`BTC6_M15_TWO_PIVOT_P3_BROAD_N_236_886`

### 条件

1. M15 EMA20/EMA200の方向を確認。
2. EMA差がATR14の0.02倍以上になった後の各EMA200タッチを対象。
3. タッチ前24時間以内の直近確定ピボットからA-Bを決める。
4. タッチ後最初の確定押し安値／戻り高値をCとする。
5. BC/AB戻し率が0.236～0.886。
6. ピボット幅3の2点斜めラインを使用。
7. M15終値でラインを抜け、次のM15始値で入る。
8. C外側30pipsをSL、AB=CDをTP。
9. 純利益50pips以上、`1 < RR < 3`。
