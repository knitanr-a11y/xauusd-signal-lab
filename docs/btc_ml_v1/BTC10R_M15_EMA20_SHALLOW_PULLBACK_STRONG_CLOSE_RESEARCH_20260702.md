# BTC10R 負け削減フィルタ研究

作成日: 2026-07-02

## 結論

BTC10 R2.25のエントリー候補から、次の2条件を満たすものだけ残す研究候補を作成した。

```text
BTC10R_M15_EMA20_SHALLOW_PULLBACK_STRONG_CLOSE_R225
```

- 直前M15終値のEMA20逆行幅が0.6 ATR14以下
- シグナルM15終値がトレンド方向側の上位15%以内
  - LONG: close location >= 0.85
  - SHORT: close location <= 0.15

TP 2.25R、SL、スプレッド、エントリー時刻、同一M5でのSL優先は親候補と同じ。

## 選定監査

フィルタ候補の数値順位付けはTRAIN・DEVだけで実施した。VALIDATIONと開封済み2026は固定後の確認にのみ使用した。

ただし親候補のVALIDATION・2026は既に開封済みであるため、この改善はpost-hoc研究であり、新しいholdoutではない。

次の未使用フォワード境界:

```text
2026-07-02 02:15:00 UTC より後
```

直近4本M15の方向モメンタム条件はTRAIN・DEVでは強かったが、除外側がVALIDATION・2026で強く利益を残したため、過剰適合の兆候として不採用にした。

採用した条件は、押し深さ0.5/0.6/0.75、終値強度0.85の近傍でTRAIN・DEV・VALIDATION・2026がすべてプラスだった。終値強度0.90はTRAIN・DEVが各30件まで減るため除外した。

## DD制御の別案

シグナルや出口をさらに変更せず、次のリスクオーバーレイを適用する研究を追加した。

```text
BTC10R_SAFE_RISK_OVERLAY_V1
```

- BTC10R通常リスクを標準候補の0.20倍
- BTC10Rで2連敗後は0.10倍
- 次のBTC10R勝ちで0.20倍へ復帰

R正規化では、親BTC10Rの合計66R・最大DD8Rに対し、連敗半減後は合計59.875R・最大DD5.875R。利益低下9.28%でDDを26.56%削減した。

既存5候補へ0.20倍で追加した正規化診断では、合計Rは14.56%増、DD増加は6.85%に抑えられた。
