# BTC-3 動画EMA手法 探索結果

## 固定したルール

- 4時間足EMA20/EMA200のクロス後、最初のEMA20タッチを基準足とする。
- EMA20を実体で抜けても許可。
- **EMA200否定はエントリー前だけ**。エントリー前にEMA200を終値で抜ける、またはEMA20が再クロスした場合はセットアップを無効にしてエントリーを見送る。
- **エントリー後はEMA200を割っても途中決済しない。** 事前に置いた構造的SL、TP1、TP1後の建値、TP2だけで決済する。
- 基準足の高値／安値を後続H4足が終値で抜けた時点で判定し、その時刻と一致するM5始値で入る。
- タッチ後の経過本数に上限なし。同一クロスで一度だけ。
- SLはタッチ足からトリガー足までの押し安値／戻り高値の外側に `max($30, H4 ATR14×0.1)`。
- 左側の確定済みH4スイングを利確候補とする。50pips未満またはRR 1:1未満の水準は飛ばし、最初の適格水準で半利確、残りは建値。次の水準で全決済。
- CSV `time` は始値。H4判定時刻は `time+4時間`。
- スプレッド主計算は$30。$20/$25/$30で感度確認。

公式実行入口:

```text
scripts/btc_ml_v1/research/run_btc3_video_ema_user_contract.py
```

この入口は、エントリー後EMA200決済を強制的に無効にする。

### 現段階の扱い

- `V3_SEPARATION_05ATR` は件数をほぼ残しながら探索期間PFが最も高く、比較候補として有力。
- `V4_BALANCED_2OF3` は少し厳しい中間候補。
- `V1` は探索PFが1.18まで低下し、12本継続だけでは良い定義になっていない。
- `V5` は正しい損切り契約ではPF0.72で、件数も2件しかないため候補から外す。
- サンプルが少ないため、V3を確定条件にはしない。V0/V3/V4を並行候補として残す。

## 基準モデルの訂正結果

前回のPF2.830は、EMA200割れをエントリー後の途中決済に使ってしまった誤った結果だったため無効とする。

正しい契約では:

- 探索：8件、PF 1.372、平均 +40.22pips。
- 確認：5件、PF 9.836、平均 +237.61pips。
- 合計：13件、PF 2.512、平均 +116.14pips、最大DD 522.64pips。
- 確認期間は5件しかないため、PF 9.8を実力値とは扱わない。

## 頑健性

- スプレッド$20/$25/$30で大きな崩れはない。
- スイングpivot 2/3/5、lookback 250/500の比較でも複数設定でプラスを維持。
- エントリー後EMA200決済は動画手法のルールではないため、正式評価には使用しない。
- EMA200の否定判定をヒゲに厳格化する案は、エントリー前の感度分析としてのみ扱う。

## 注意点

- リスク幅の中央値は約192.5pips、最大約496.7pipsで広い。固定ロットではなくSL距離に応じたロット調整が必要。
- 発生頻度は月1回未満。既存のBTC候補を置き換えるものではなく、別系統として加える候補。
- 正式成果物と条件選定には2026年以降の損益を含めていない。最終判定は今後のフォワード監視で行う。

動画手法は落とし込み可能で、正しい損切り契約でも予備結果はプラス。ただし13件では候補確定不可。次はV0/V3/V4を固定したまま長期データ追加またはフォワード監視を行う。
