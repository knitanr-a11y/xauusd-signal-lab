# BTC-7R M15インパルス継続・高勝率化

## 目的

BTC7の238件は件数を大きく増やせる一方、勝率42.44%、137敗だった。

ユーザー要望に従い、未来損益を使わず、エントリー時点で分かる条件だけで負けを減らし、勝率を上げた。

## 選定手順

2026年以降の損益は一切使用していない。

探索期間をさらに二分した。

- TRAIN: 2024-08-01から2025-02-01未満
- DEV: 2025-02-01から2025-07-01未満
- 正式確認: 2025-07-01から2026-01-01未満

TRAINとDEVだけで条件を選び、条件凍結後に正式確認期間を開いた。

比較したものは、予定リスク、M15インパルス強度、ローソク実体・ヒゲ、H1トレンド強度・傾斜、ATR・出来高状態、H4/D1整合、過去シグナル密度、H1トレンド継続時間、TP倍率など。すべてエントリー時点で確定済みの情報だけを使った。

月・曜日を後付け除外するルールは採用していない。

## 残った条件

候補ID:

`BTC7R_M15_IMPULSE_HIGH_WIN_24_96_M22_R110`

BTC7の基本条件へ以下を追加する。

1. H1トレンド条件が成立してから24時間以上経過している。
2. H1トレンド条件の継続時間が96時間以下。
3. M15シグナル足の値幅がATR14の2.2倍以上。
4. 予定純リスクは100pips以下。
5. TPはスプレッド込み1.1R。
6. TPまでの純利益が50pips未満になる取引は見送る。

### H1トレンド継続時間

H1条件を確定済みH1だけでM15へas-of結合する。

LONG:

- H1 EMA50 > EMA200
- H1 EMA200が4時間前より上
- EMA50とEMA200の距離がH1 ATR14の0.5倍以上

SHORTは逆。

この条件がM15上で連続している時間を数え、24～96時間だけを採用する。

トレンド開始直後の不安定なインパルスと、長く続き過ぎた末期インパルスを除外する考え方。
