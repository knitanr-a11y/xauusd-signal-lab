# BTC-9 M15前日高値・安値ブレイク候補

## 目的

BTC4・BTC5・BTC6・BTC7Rとは異なる価格構造ベースの候補を追加し、評価済み件数を積み上げる。

完了した比較は次の2系統。

- 前日高値・安値の順張りブレイク
- 前日高値・安値のスイープ逆張り

UTCセッションのオープニングレンジブレイクも広いグリッドを試作したが、探索実行時間内に全比較が完了しなかった。この未完了結果はBTC9の条件選定・成績・採否には一切使っていない。

条件選定には2026年以降の損益を使っていない。

## 選定手順

- TRAIN: 2024-08-01から2025-02-01未満
- DEV: 2025-02-01から2025-07-01未満
- 正式確認: 2025-07-01から2026-01-01未満

TRAINとDEVで十分な件数があり、両方のPFが1.1を超える候補だけを残した。

前日高値・安値ブレイク系では、TRAINとDEVのうち低い方のPFが最も高かった十分件数の条件を凍結し、その後に正式確認期間を開いた。

## 暫定候補

`BTC9_M15_PREVDAY_BREAKOUT_H1_CLV85_RISK100_R110`

## 条件

### 前日レベル

- UTC日足の確定済み前日高値・安値を使う。
- 前日高値・安値は翌日の00:00 UTC以降だけ使用可能。
- 当日形成中の日足高値・安値は使わない。

### H1方向

LONG:

- 確定済みH1 EMA50 > EMA200
- H1 EMA200が4時間前より上
- `abs(EMA50-EMA200) / H1 ATR14 >= 0.5`

SHORTは逆。

### M15シグナル

LONG:

- M15終値が前日高値を上抜く。
- H1 LONG条件が成立。
- 終値がM15ローソク足値幅の上位15%以内。

SHORT:

- M15終値が前日安値を下抜く。
- H1 SHORT条件が成立。
- 終値がM15ローソク足値幅の下位15%以内。

1 UTC日につき、最初に成立したLONGまたはSHORTの1件だけを候補にする。

### エントリー・SL・TP

- M15シグナル足確定後、次の正確なM5始値でエントリー。
- LONGのSLはシグナル足安値－M15 ATR14×0.1。
- SHORTのSLはシグナル足高値＋M15 ATR14×0.1。
- スプレッド30ドル込みの予定純リスク100pips以下。
- 純利益50pips以上。
- TPはスプレッド込み1.1R。
- 同一M5足でSLとTPが両方成立する場合はSL優先。

## パラメーター近傍

次の近傍条件もTRAIN・DEV・正式確認のすべてでプラスを維持した。

- ブレイク余裕0または0.1ATR
- 終値位置上位・下位15%
- 予定リスク上限100pips
- TP1.1Rまたは1.25R

選んだ条件は、十分件数のある前日ブレイク候補の中でTRAINとDEVの低い方のPFが最も高かったもの。正式確認期間の成績は条件選定に使っていない。
