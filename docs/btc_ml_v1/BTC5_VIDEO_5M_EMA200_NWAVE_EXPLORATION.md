# BTC-5 5分足 EMA200・N波動動画手法

## ユーザー確定ルール

- M5のEMA20・EMA200、適用価格はClose。
- EMA20がEMA200の上ならLONG、下ならSHORT。
- EMA20が逆側へクロスするまで、2回目以降を含むEMA200タッチはすべて有効。
- ヒゲだけのEMA200接触もタッチ成立。
- 連続接触足は1回の接触群として扱い、一度EMA200から離れた後の再接触は別セットアップ。
- 斜めラインまたはネックラインをM5終値で抜け、次のM5始値でエントリー。
- A-Bはタッチ前の直近トレンド波、TPはAB=CDのN波動完成点。
- SLはC点の外側30pips。BTC契約では価格差300ドル。
- 純利益50pips未満は見送り。
- RRは厳密に `1 < RR < 3`。

## 機械化した比較

- 確定ピボット幅: 2 / 3 / 5。
- 2点ピボットの斜めライン。
- 3点以上の回帰線（R² 0.70以上）。
- ダブルトップ／ダブルボトムのネックライン。
- N波動のBC/AB戻し率:
  - 0.236～0.886
  - 0.382～0.786
  - 0.500～0.886

候補選択にはエントリー後の情報を使用していない。2026年以降はエントリー候補のみを記録し、損益は評価していない。

## 比較結果

ダブルトップ／ダブルボトム方式は全体で不安定。回帰線方式は3～4件しか出ず、候補判断に必要な件数がない。

2点ラインでは:

- ピボット幅3は確認期間PF 0.470。
- ピボット幅5は探索・確認ともマイナス。
- ピボット幅2に標準N波動戻し率0.382～0.786を加えた方式だけが、探索期間と確認期間の両方でPF 1を上回った。

## 暫定候補

`BTC5_TWO_PIVOT_P2_CLEAN_N_382_786`

### 客観条件

1. EMA20/EMA200の方向が確定し、両EMA差がATR14の0.02倍以上になる。
2. 逆クロスまでの各EMA200タッチを検出する。
3. タッチ前24時間以内の直近確定ピボットからA-Bを決める。
4. タッチ後最初の確定押し安値／戻り高値をCとする。
5. BC/AB戻し率が0.382～0.786。
6. SHORTはBとその後の切り上げ安値、LONGはBとその後の切り下げ高値を結ぶ。ピボット幅は2。
7. M5終値で斜めラインを抜け、次のM5始値で入る。
8. C外側30pipsをSL、AB=CDをTPとする。
9. 純利益50pips以上かつ `1 < RR < 3` のみ残す。
