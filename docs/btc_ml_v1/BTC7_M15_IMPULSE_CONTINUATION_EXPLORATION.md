# BTC-7 M15インパルス継続候補の探索

## 目的

YouTube候補3本だけでは評価済み件数が合計36件しかないため、別ベクトルで件数を増やす。

今回は、既存のEMAタッチ・N波動とは異なる以下の系統を事前定義して比較した。

- H1ドンチャンブレイク
- H1ボリンジャー収縮後のブレイク
- M15トレンド押し戻り
- M15ボリンジャー逆張り
- M15インサイドバー
- M15 EMA20/50クロス
- M15 RSIモメンタム
- M15大陽線・大陰線のインパルス継続

候補を無理に増やさず、探索・確認期間の両方でPF 1.1超、合計35件以上を客観ゲートとした。

## 広い探索結果

最初の5系統では、客観ゲートを通る設定は0件だった。

- H1ドンチャンは探索・確認とも全体的にPF 1未満。
- H1収縮ブレイクは両期間でマイナス。
- M15押し戻りは探索PFが1.08前後まで届いたが、確認期間でPF 1を割った。
- M15逆張りは確認期間のみ良く、探索期間で崩れた。
- M15インサイドバーは高頻度だが両期間で優位性を確認できなかった。

追加したモメンタム系のうち、客観ゲートを通ったのは次の1方式だけだった。

`BTC7_M15_IMPULSE_CONTINUATION_RISK100`

## 条件

### 上位足方向

- H1 EMA50 > EMA200、かつEMA200上向きならLONG。
- H1 EMA50 < EMA200、かつEMA200下向きならSHORT。
- `abs(EMA50-EMA200) / H1 ATR14 >= 0.5`。

H1条件は、確定済みH1だけをM15へas-of結合する。

### M15インパルス

- M15の高値－安値がM15 ATR14の2倍以上。
- LONGは終値がローソク足値幅の上位15%以内。
- SHORTは終値が下位15%以内。
- LONGはM15 EMA20より上、SHORTはEMA20より下で確定。
- 同方向のインパルス足が連続する場合は、最初の1本だけを候補にする。

### エントリー

- M15シグナル足の確定後。
- シグナル足の終了時刻と一致するM5始値でエントリー。

### SL・TP

- LONG: シグナル足安値－M15 ATR14×0.1。
- SHORT: シグナル足高値＋M15 ATR14×0.1。
- スプレッド30ドル込みの予定純リスクが100pips以下だけ残す。
- 純利益50pips以上。
- TPはスプレッド込みで2R。
- 同一M5足でSLとTPが両方成立する場合はSL優先。

## 同時保有

グローバルな1ポジション制限は使用していない。

- BTC7内の最大同時保有: 4ポジション
- 既存BTC7ポジション保有中に発生した追加エントリー: 37件

固定ロットを決める前に、最大4ポジション同時の口座リスクを確認する必要がある。
