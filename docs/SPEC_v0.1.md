# SPEC v0.1

## 目的

XAUUSD（ゴールド）専用のシグナル検証ツールを作る。

最初の目的は自動売買ではなく、裁量判断を補助するためのシグナル通知ツールを作ること。

最終的には以下を目指す。

```text
MT4からデータ取得
Pythonで検証
バックテスト
機械学習フィルター
Discord通知
AIによる状況評価
人間が最終判断
```

---

## 基本仕様

```text
対象：XAUUSD
メイン足：M15
上位足：H1
売買方向：BUY / SELL 両方
スタイル：H1方向への順張り
初期RR：1:1.5
エントリー：M15シグナル足確定後、次のM15足始値
TP：SL幅 × 1.5
SL：今回の押し目/戻り目区間の外側
```

---

## H1環境認識

### BUY環境

```text
H1 EMA20 > H1 EMA50
かつ
H1終値 > H1 EMA20
```

### SELL環境

```text
H1 EMA20 < H1 EMA50
かつ
H1終値 < H1 EMA20
```

H1情報をM15に結合する際は、M15足の時点で確定済みのH1足だけを使う。
未確定H1足を使ってはいけない。

## M15シグナル候補

### BUY候補

```text
1. H1がBUY環境
2. M15でEMA20付近まで押し目
3. Pine互換MACDで強気ヒドゥンダイバージェンス
4. MACD反転または改善
5. SLを今回押し目安値の下に置ける
6. TPをSL幅×1.5に置ける
7. 直近高値まで近すぎない
```

### SELL候補

```text
1. H1がSELL環境
2. M15でEMA20付近まで戻り目
3. Pine互換MACDで弱気ヒドゥンダイバージェンス
4. MACD反転または悪化
5. SLを今回戻り高値の上に置ける
6. TPをSL幅×1.5に置ける
7. 直近安値まで近すぎない
```

## MACD仕様

MACDはTradingView / Pine Scriptで使っている設定値と同じ値を使う。
MT4のMACD値をそのまま使わず、MT4からはOHLCだけ出力し、Python側でPine互換のMACDを再計算する。

初期設定候補：

```text
MACD Fast EMA：6
MACD Slow EMA：13
MACD Signal：4
```

この数値はTradingView側の設定と完全に合わせる。

### 使用値

```text
主判定：MACDライン
補助候補：MACDシグナルライン、MACDヒストグラム、ヒストグラム変化量
```

## ダイバージェンス仕様

### 通常ダイバージェンス

通常ダイバージェンスは、初期段階ではエントリー条件ではなく見送り要素として扱う。

#### 弱気通常ダイバージェンス

```text
価格：前回高値を更新
MACD：前回高値時のMACDを更新していない
意味：上昇の勢いが弱い可能性
BUY見送り要素
```

#### 強気通常ダイバージェンス

```text
価格：前回安値を更新
MACD：前回安値時のMACDを更新していない
意味：下落の勢いが弱い可能性
SELL見送り要素
```

### ヒドゥンダイバージェンス

A案は順張りなので、初期ロジックではヒドゥンダイバージェンスを重視する。

#### 強気ヒドゥンダイバージェンス

```text
価格：安値を切り上げ
MACD：安値を切り下げ
意味：上昇トレンド継続候補
BUY条件
```

#### 弱気ヒドゥンダイバージェンス

```text
価格：高値を切り下げ
MACD：高値を切り上げ
意味：下降トレンド継続候補
SELL条件
```

## 高値・安値判定仕様

高値・安値は用途ごとに分ける。

```text
1. ダイバージェンス比較用の高安値
2. SL用の高安値
3. 利確余地確認用の高安値
```

すべてを同じ高安値で処理しない。

### 確定スイング高値

```text
対象足の高値が、左3本の高値より高く、右2本の高値より高い
```

### 確定スイング安値

```text
対象足の安値が、左3本の安値より低く、右2本の安値より低い
```

初期値：

```text
SWING_LEFT = 3
SWING_RIGHT = 2
```

ただし、設定で変更可能にする。

### スイング確定タイミング

スイングは、右側の足が確定して初めて使える。

例：

```text
10:00の足がスイング高値だったとしても、
右2本が必要なので、
10:30のM15足が確定するまで使用不可。
```

## 通常ダイバージェンスの比較方法

### 弱気通常ダイバージェンス

```text
前回基準：確定済みスイング高値
今回基準：現在の確定足が前回高値を更新
条件：
  現在足の高値 > 前回スイング高値
  かつ
  現在足のMACD < 前回スイング高値時のMACD
```

### 強気通常ダイバージェンス

```text
前回基準：確定済みスイング安値
今回基準：現在の確定足が前回安値を更新
条件：
  現在足の安値 < 前回スイング安値
  かつ
  現在足のMACD > 前回スイング安値時のMACD
```

今回側の高値・安値は、スイング確定まで待たず、価格更新した確定足で判定する。

---

## ヒドゥンダイバージェンスの比較方法

### BUYの場合

```text
前回基準：前回の確定スイング安値
今回基準：今回の押し目区間の最安値
条件：
  今回押し目安値 > 前回スイング安値
  かつ
  今回押し目安値時のMACD < 前回スイング安値時のMACD
```

### SELLの場合

```text
前回基準：前回の確定スイング高値
今回基準：今回の戻り目区間の最高値
条件：
  今回戻り高値 < 前回スイング高値
  かつ
  今回戻り高値時のMACD > 前回スイング高値時のMACD
```

## 押し目・戻り目区間

### BUYの押し目区間

```text
M15価格がEMA20付近に接近
↓
MACDが反転または改善
↓
その区間内の最安値を今回押し目安値とする
```

### SELLの戻り目区間

```text
M15価格がEMA20付近に接近
↓
MACDが反転または悪化
↓
その区間内の最高値を今回戻り高値とする
```

EMA20付近の判定は固定pipsではなくATR基準にする。

## SL/TP仕様

### BUY

```text
エントリー：シグナル足確定後、次足始値
SL：今回押し目区間の最安値の少し下
TP：エントリー価格 + SL幅 × 1.5
```

### SELL

```text
エントリー：シグナル足確定後、次足始値
SL：今回戻り目区間の最高値の少し上
TP：エントリー価格 - SL幅 × 1.5
```

## バックテスト集計項目

```text
総トレード数
勝率
平均R
PF
最大DD
最大連敗
BUY成績
SELL成績
時間帯別成績
曜日別成績
月別成績
年別成績
SL幅別成績
時間帯×方向別成績
```

RR1.5固定の場合、損益分岐勝率は約40%。

```text
必要勝率 = 1 / (1 + 1.5) = 40%
```

実運用を考えると、初期目安は以下。

```text
勝率：45%以上
PF：1.2以上
平均R：プラス
最大連敗：許容範囲内
月別成績：極端に偏らない
```
